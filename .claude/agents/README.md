# Subagent Gang & Contributor Collective — `unsigned-gg/gs`

This directory defines the automated subagent personas and the contributor roster for the
`gs` (Godseat Control Surface) repository.

## Subagent Roles

- **`gs-foreman`**: Orchestrates critical path work, plans builder/critic waves, and verifies landing gates.
- **`gs-builder`**: Bounded builder. Fabricates policy classifiers, duty clocks, and sensing probes.
- **`gs-critic`**: Adversarial reviewer. Audits diffs for policy bypass hazards, case flaws, and unsafe code.
- **`gs-engineer`**: General systems engineer for researching policy lattices, sensing, and duty clocks.

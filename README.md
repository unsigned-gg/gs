# gs — Godseat Control Surface

> **Perception before action, cryptographic gate tiers, and operator cluster sensing.**

Part of the [unsigned](https://unsigned.gg) systems ecosystem.

## Overview
`gs` provides the formal Rust primitives for the Godseat control plane:
* **Gate Tiers:** Evaluation of policy gates (`Green`, `Yellow`, `Red`, `Never`).
* **Estate Sensing:** Sensing daemon states, sessions, and live pods.
* **Audit Trail:** Attestation records and statutory duty clocks.
